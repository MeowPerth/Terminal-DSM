Terminal：在 DSM 桌面窗口里直接使用的终端，认证就是 DSM 登录，不需要再输一次密码。

权限

  • administrators 组：打开即为 root；
  • 其他 DSM 用户：以本人账号登录（自己的家目录、自己的权限）；
  • 未登录访问会被跳转到 DSM 登录页；
  • 由 /var/packages/terminal/var/terminal.conf 的 ALLOW_ALL_USERS 控制是否允许普通用户使用。

复制 / 粘贴

  • 复制：鼠标拖动选中，松开即自动复制；也可按 Ctrl + Shift + C；
  • 粘贴：Ctrl + Shift + V；
  • tmux 内复制的文本会通过 OSC 52 自动进入系统剪贴板。

右键菜单（tmux）

  • 在终端内点右键会弹出 tmux 的上下文菜单，松开右键不会消失；
  • 菜单项可用鼠标左键点，或按对应快捷键：h 左右分屏、v 上下分屏、x 关闭窗格、r 重启窗格、m 标记、z 缩放；
  • 关闭菜单：点菜单项、点其它位置或按 Esc。

tmux 多窗口 / 分屏

  • 新建窗口 Ctrl+B c；切换 Ctrl+B n/p 或 Ctrl+B 1..9；
  • 左右分屏 Ctrl+B %，上下分屏 Ctrl+B "，面板间用 Ctrl+B 方向键；
  • 翻历史 Ctrl+B [（q 退出）；关闭窗口 Ctrl+B &；
  • Ctrl+B d 断开但保留会话——直接关窗口也会保留，重新打开会接回原来的现场。

安全

  • 入口只接受有效的 DSM 会话（校验 cookie + SynoToken）；
  • 服务只监听 unix socket，不占用任何 TCP 端口，外部无法直连；
  • WebSocket 做同源校验，防止跨站连接。
