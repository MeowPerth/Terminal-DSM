Terminal: a terminal inside a DSM desktop window. Your DSM login is the authentication - no second password prompt.

Permissions

  • administrators: opens as root;
  • other DSM users: sign in as themselves (own home directory, own permissions);
  • Access without a DSM session is redirected to the DSM sign-in page;
  • Controlled by ALLOW_ALL_USERS in /var/packages/terminal/var/terminal.conf.

Copy / Paste

  • Copy: drag to select - it is copied on release, or press Ctrl + Shift + C;
  • Paste: Ctrl + Shift + V;
  • Copies made inside tmux are forwarded to the system clipboard via OSC 52.

Right-click menu (tmux)

  • Right-click inside the terminal opens the tmux context menu; releasing the button does not close it;
  • Pick an item with the left button, or press its shortcut: h split left/right, v split top/bottom, x kill pane, r respawn, m mark, z zoom;
  • Close it by choosing an item, clicking elsewhere, or pressing Esc.

tmux windows and panes

  • New window Ctrl+B c; switch Ctrl+B n/p or Ctrl+B 1..9;
  • Split Ctrl+B % (side by side) or Ctrl+B " (stacked); move with Ctrl+B arrow;
  • Scrollback Ctrl+B [ (q to exit); close window Ctrl+B &;
  • Ctrl+B d detaches but keeps the session - closing the window keeps it too, reopening reattaches.

Security

  • Only a valid DSM session is accepted (cookie + SynoToken are verified);
  • The server listens on a unix socket only - no TCP port is exposed;
  • The WebSocket is same-origin checked to block cross-site connections.
